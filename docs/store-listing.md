## 详细描述

```
选择困难症的解法：把决定权交给骰子。

你标了几百个「想看」「想读」，然后每次打开都是同一批，一个都不想点。
这个扩展从你自己的豆瓣收藏里随机抽一个，抽到就去看。

■ 它做什么
· 候选来自你自己的豆瓣标记：想看、看过的电影 / 剧集 / 图书
· 抽到看过的条目会标一个「重温」，换一种心境重看
· 抽中后显示封面、年份、豆瓣评分、你的评分和短评
· 一个类别同时只有一个待看：看完了点一下，或者跳过换一个（每天有次数限制）
· 候选池页：看全部候选，按来源、时间、有没有评论筛选，把不想抽的屏蔽掉，随时恢复
· 记录页：回看抽过什么，按类别和来源筛选，导出成 JSON
· 记住抽过什么，最近的不会重复抽到

■ 它不做什么
· 不使用你的账号密码，不读取、不保存 cookie
· 不修改你在豆瓣的任何数据（不打分、不写短评、不改标记）
· 没有服务器，没有任何数据上传
· 没有广告、没有统计、没有遥测

■ 使用前提
需要先在浏览器里登录豆瓣。本扩展复用你已有的登录状态，
读取的是你自己标记为「想看 / 想读 / 看过 / 读过」的条目。

■ 非官方声明
本项目为个人开发的非官方工具，与豆瓣（北京豆网科技有限公司）无任何关联，
未获得其授权或认可。豆瓣是其权利人的商标。

■ 开源
源码采用 MIT 许可证，欢迎反馈问题。
```

## 权限用途说明（商店后台必填）

| 权限 | 填写内容 |
|---|---|
| `storage` | 在本机保存候选条目、抽取历史与屏蔽列表，避免重复请求。数据不离开用户设备。 |
| `sidePanel` | 扩展的主界面显示在浏览器侧边栏中，便于边浏览边抽取。 |
| `declarativeNetRequest` | 给豆瓣图床的图片请求补上 Referer，否则封面加载不出来。规则只作用于 `doubanio.com` 的图片请求，不改动任何请求内容，也不拦截或屏蔽任何请求。 |
| `https://*.douban.com/*` | 在豆瓣页面内读取用户本人标记的收藏条目。仅发起 GET 请求，不修改任何数据。 |
| `https://*.doubanio.com/*` | 读取豆瓣的封面图片，显示在卡片上。 |

## 数据使用声明（商店后台的 "Data usage" 表单）

全部选择**不收集**：

- 不收集个人身份信息
- 不收集健康信息
- 不收集财务与支付信息
- 不收集身份验证信息（不读取账号、密码、cookie）
- 不收集个人通讯
- 不收集位置
- 不收集网页浏览历史
- 不收集用户活动
- 不收集网站内容

勾选三项承诺：数据不用于出售、不用于与核心功能无关的用途、不用于判断信用状况。

## ⚠️ 需要你准备的东西

1. **开发者账号**：Chrome Web Store 开发者注册，一次性 $5。
2. **隐私政策 URL**：把 `PRIVACY.md` 推上 GitHub 后，用它的网页地址，例如
   `https://github.com/<你的用户名>/douban-random-picker/blob/main/PRIVACY.md`。
   商店接受 GitHub 页面作为隐私政策链接。
3. **截图**：至少一张，尺寸 1280×800 或 640×400（PNG/JPEG）。
   建议拍三张：侧边栏抽中卡片的样子、候选池页、记录页。
   需要在真实 Chrome 里装好后截图，我无法代做。
4. **提交包**：运行 `npm run package`，产物在 `dist/`。

## 提交步骤

1. 打开 <https://chrome.google.com/webstore/devconsole>
2. New item → 上传 `dist/douban-random-picker-<version>.zip`
3. 按上面的表格逐项填写
4. 审核通常 1–3 个工作日；被驳回时优先检查「单用途」与「权限理由」两项
